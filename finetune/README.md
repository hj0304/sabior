# 파인튜닝 (P4, W12-W16)

| 폴더 | 내용 |
|---|---|
| `data_gen/` | 근거 고정 SFT 데이터 합성: 질문 템플릿 x DB 샘플링 -> 도구 실행 -> 교사 모델 생성 -> 숫자 검증 필터 -> 오염 제거 |
| `sft/` | QLoRA SFT (Unsloth + TRL). 4B 로 반복, 8B 로 최종 |
| `dpo/` | 선호 최적화. chosen = 검증 통과 답변, rejected = 숫자 변조·단정·도구 미사용 답변. 8GB 에서는 ORPO 우선 검토 |
| `configs/` | 실험 설정 YAML. 모델카드에 config 경로와 데이터 해시를 기록 |
| `model_cards/` | 모델별 카드: 데이터, 하이퍼파라미터, 벤치마크 결과, 한계 |

## 4-way 비교 (게이트 4)

| 조건 | 구성 |
|---|---|
| A | 프론티어 API + 도구 (상한) |
| B | 오픈 8B 베이스 + 도구 (기준선) |
| C | 오픈 8B 파인튜닝 + 도구 (목표) |
| D | 오픈 8B 파인튜닝, 도구 없음 (대조군) |

## 절대 규칙
- 학습 데이터의 모든 숫자는 도구 결과에 존재해야 한다. 필터 통과율을 기록한다.
- 평가셋(`evals/benchmark`)의 선수-시즌 조합은 학습 데이터에서 제외한다.
- 클라우드 GPU 사용은 P4 전체에서 1-2회로 제한한다.
