# ADR 0001. KBO 단독, 스키마는 리그 중립, MLB 는 참조

- 날짜: 2026-09-04
- 상태: 확정

## 맥락
관심 리그는 KBO 이고 보상선수·신인 드래프트는 KBO 고유 개념이다. 다만 KBO 데이터는 얇고, MLB 는 지표 검증에 쓸 공개 자료가 풍부하다.

## 결정
KBO 를 본 데이터로 하고 서비스도 KBO 만 한다. 모든 테이블에 `league` 컬럼을 두고 리그·연도별 상수를 분리해 MLB 확장 가능성을 남긴다. MLB 데이터는 지표 엔진 검증, 에이징 커브 등 방법론 개발에만 쓴다. FA 모델은 시장 구조가 달라 리그별로 따로 학습한다.

## 결과
지표 엔진은 Lahman 으로 먼저 검증한 뒤 KBO 에 적용한다. MLB 병행 서비스(작업 2배)는 하지 않는다.
