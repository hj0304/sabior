# ADR 0005. 18주 코어 + 2주 버퍼, 단축 규칙과 범위 축소 순서를 사전 확정

- 날짜: 2026-09-04
- 상태: 확정

## 맥락
1인 프로젝트이고 가능한 한 빨리 끝내고 싶다. 버퍼 없는 16주 강행은 게이트를 건너뛰게 만든다.

## 결정
2026-09-07 시작, 18주 코어(P0-P5) + 2주 버퍼. 단축 규칙: P1 은 MLB Lahman 부터, P2 의 FA 3과제는 MVP 만, P4 학습은 야간에 돌리고 낮에 P5 를 진행. 지연 시 범위 축소 순서: 드래프트, 보상선수, FA 행선지, UI 최소화, 선호 최적화 생략. 평가셋, 백테스트 하네스, SFT, 4-way 비교 리포트는 빼지 않는다.

## 결과
게이트 미통과 시 다음 단계로 넘어가지 않는다. 매주 월요일 MVP 를 먼저 정의한다.
