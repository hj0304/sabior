# ADR 0011. 프론티어 API 자동 비교는 하지 않는다

- 날짜: 2026-09-26
- 상태: 확정 (사용자 결정)

## 맥락
4-way 비교 설계의 조건 A(프론티어 API 모델 + 도구)는 상한선 역할이다. Anthropic 어댑터는 구현돼 있지만 API 키 비용 때문에 사용자가 자동 비교를 원하지 않는다.

## 결정
- API 키를 쓰는 자동 비교는 하지 않는다. `AnthropicAdapter` 는 코드로만 남긴다.
- 상한선이 필요하면 Claude Code 세션이 직접 도구를 호출해 같은 문항에 답하고, 그 답을 채점기로 평가한다 (수동 조건 A). 필수 단계는 아니다.
- SFT 교사 답변도 API 대신 Claude Code 세션이 작성하거나, 도구 결과를 채우는 규칙 기반 템플릿으로 만든다.

## 결과
- 게이트 3·4 의 비교표에서 조건 A 는 "수동 상한선(선택)" 으로 표기한다. 핵심 비교는 B(베이스+도구) vs C(파인튜닝+도구) vs D(파인튜닝 단독).
