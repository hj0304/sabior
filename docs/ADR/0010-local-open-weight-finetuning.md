# ADR 0010. 로컬 오픈 모델 파인튜닝으로 진행

- 날짜: 2026-09-25
- 상태: 확정 (사용자 결정)

## 맥락
"굳이 로컬 LLM 을 쓰는 이유"를 검토했다. 서비스 품질만 보면 프론티어 API 모델 + 도구가 앞선다. 반면 오픈 모델은 직접 파인튜닝할 수 있고, API 비용이 없고, 데이터를 외부로 보내지 않는다. 오픈 모델과 로컬 장비는 별개 선택이며, 클라우드 GPU 로 8B 이상을 학습하는 대안도 있다.

## 결정
- 맞춤형 파인튜닝 경험을 목표로 **오픈 가중치 모델을 로컬(RTX 4070 Laptop, WSL2)에서 학습**한다.
- 후보는 W2 실측을 통과한 Qwen3-4B-Instruct-2507 과 A.X-4.0-Light 7B (ADR 0009).
- 클라우드 GPU 는 원래 계획대로 P4 전체에서 1~2회 탈출구로만 쓴다.
- 비교 실험의 상한선(조건 A)은 프론티어 API 모델로 유지한다. 웹서비스 초기 채팅은 API 모델로 열고, 파인튜닝 모델은 품질·비용이 맞을 때 교체한다 (docs/web_service_roadmap.md).

## 결과
- P4 계획 변경 없음. 8B 급은 로컬 후보에서 제외된 상태를 유지한다.
