# ADR 0003. 파인튜닝은 조건부가 아닌 필수 단계

- 날짜: 2026-09-04
- 상태: 확정

## 맥락
결과물 품질만 보면 도구 호출 에이전트에 프론티어 API 를 붙이는 편이 빠르다. 그러나 이 프로젝트의 목표에는 파인튜닝을 직접 경험하는 것이 포함된다.

## 결정
P4 에 5주를 고정 배정하고 SFT 와 선호 최적화까지 반드시 수행한다. 성과는 4-way 비교(API+도구 / 베이스+도구 / 파인튜닝+도구 / 파인튜닝 단독)로 측정한다.

## 결과
지연이 생기면 다른 과제(드래프트, 보상선수, FA 행선지, UI)를 먼저 줄인다. 선호 최적화는 마지막에 줄일 수 있지만 SFT 는 줄이지 않는다.
