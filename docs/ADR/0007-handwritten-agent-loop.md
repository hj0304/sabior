# ADR 0007. 에이전트 루프는 프레임워크 없이 직접 구현

- 날짜: 2026-09-04
- 상태: 확정

## 맥락
학습 목적의 프로젝트이며 도구 호출 루프 자체는 수백 줄로 충분하다. 프레임워크는 디버깅과 로그 형식 통제를 어렵게 한다.

## 결정
`agent/runner.py` 에 함수호출 루프를 직접 구현하고 `agent/tools/registry.py` 로 도구와 로그를 관리한다. 모델 어댑터는 Ollama 와 Anthropic API 두 가지.

## 결과
도구 호출 로그가 SFT 데이터 합성과 근거 추적성 채점에 그대로 재사용된다. 프레임워크는 멀티 에이전트 등 필요가 생길 때 재검토한다.
