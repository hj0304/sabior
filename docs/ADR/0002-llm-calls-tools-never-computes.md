# ADR 0002. LLM 은 계산하지 않고 도구를 호출한다

- 날짜: 2026-09-04
- 상태: 확정

## 맥락
언어 모델은 산술과 기록 암기에 약하다. 숫자 환각 하나가 세이버메트리션 페르소나의 신뢰를 무너뜨린다.

## 결정
수치 계산과 예측은 `stats/`, `models/` 가 수행하고 LLM 은 질문 해석, 도구 선택, 결과 해석과 논증만 맡는다. 답변의 모든 숫자는 도구 호출 로그에 존재해야 하며 이를 자동 검사한다.

## 결과
파인튜닝 목표는 지식 주입이 아니라 도구 사용 습관과 추론 스타일이 된다. 순수 파인튜닝으로 기록을 외우게 하는 방식은 버린다.
