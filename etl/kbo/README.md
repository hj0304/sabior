## 점검 항목

- [ ] KBO 공식 기록실 robots.txt 확인. 허용·차단 경로 기록
- [ ] KBO 공식 기록실 이용약관에서 자동 수집·재배포 관련 조항 확인
- [ ] STATIZ 이용약관 확인. 대조용 최소 수집만 허용되는지, 아니면 수동 대조로 제한할지 결정
- [ ] 요청 간격 2초 이상, 야간 수집, 재수집 금지(캐시 사용) 원칙 확정
- [ ] User-Agent 에 연락처 포함 (.env SABIOR_CONTACT)
