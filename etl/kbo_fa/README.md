# KBO FA 계약 데이터 (2021~2026 시장)

FA 금액·행선지·보상선수 모델(P2 W8)의 학습·평가 데이터. 야구나라 데이터와 별개로, 공개된 계약 사실을 정리한다.

## 출처와 이용 원칙

| 항목 | 내용 |
|---|---|
| 1차 추출 | 나무위키 "KBO 리그/역대 FA/<연도>" 문서의 계약 현황 표. robots.txt 가 `/w/` 경로를 모든 수집기에 허용. 문서당 1회만 받아 `data/raw/kbo_fa/namu/` 에 캐시 |
| 추출 범위 | 계약 사실만 (선수, 등급, 원소속, 계약 구단, 연수, 총액, 보장액, 계약금, 연봉 총액, 옵션, 보상금, 보상선수, 발표일). 문서의 서술·평가 문장은 가져오지 않는다 |
| 라이선스 | 나무위키 본문은 CC BY-NC-SA 2.0 KR. 계약 금액 같은 사실 정보에는 저작권이 없지만, 원본 CSV 는 리포에 올리지 않는다 (`data/` 는 git 제외) |
| 검증 | 나무위키는 2차 출처다. 기사로 대조한 행은 `verification.csv` 에 기사 URL 과 함께 기록하고 DB 의 source 를 `namu_wiki+news` 로 표시 |
| 공개 서비스 | 웹서비스에 노출하기 전에 전 행을 기사·KBO 보도자료로 대조한다 (ADR 0008 의 공개 규칙) |

## 파이프라인

```bash
uv run python -m etl.kbo_fa.namu_parse   # data/processed/kbo_fa_contracts.csv
uv run python -m etl.kbo_fa.load         # contracts, transactions 테이블 (source = namu_wiki / namu_wiki+news)
```

- 시장 연도 규칙: 문서 연도 = 계약 후 첫 시즌. `market_year=2026` = 2025년 11월 개장 시장.
- 동명이인: 키를 (이름, 원소속팀)으로 둔다. 2026 시장 최원준 두 명(NC→kt, 두산 잔류)이 분리된다.
- 표 형식이 연도마다 다르다. 2021~2022 는 팀을 로고 이미지로만 표시해 링크 제목에서 팀 이름을 읽는다. 2023~ 는 요약표(등급·보상금·보상선수)가 따로 있다.
- 보장액이 없는 연도는 계약금 + 연봉 총액으로 계산하고 `guaranteed_derived=True` 로 표시한다.
- 해외 구단 계약(2021 양현종 텍사스)은 `contract_type=OVERSEAS` 로 표시하고 DB 에는 넣지 않는다.
- player_id 는 임시 규칙 `KBO_N{이름}_{추정 출생연도}`. 야구나라 데이터가 오면 매핑해 교체한다.
