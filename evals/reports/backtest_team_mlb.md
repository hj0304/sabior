# 백테스트 리포트: 팀 성적 예측 (MLB, 2015~2025)

- 생성: 2026-09-25
- 코드: `models/team_sim/sim.py`, `backtest/team.py`
- 원자료: `backtest_mlb_team_2015_2025.csv`, `backtest_mlb_team_2015_2025_postseason.csv`
- 재현: `uv run python -m backtest.team --league MLB --from 2015 --to 2025`

## 방법

선수 예측(타자 Marcel+, 투수 Marcel)을 팀 단위로 합쳐 득점·실점을 추정하고, Pythagenpat 승률과 몬테카를로 1만 회로 승수 분포·포스트시즌 확률을 낸다. 입력은 전부 전년도 말 시점 데이터다.

출장 분배는 두 방식으로 평가했다. Lahman 에 개막 전 로스터가 없기 때문이다.

| 방식 | 내용 | 누출 |
|---|---|---|
| prior_roster | 전년 소속팀 + Marcel 예상 타석·이닝 | 없음. 오프시즌 이적은 반영 못 함 |
| actual_usage | 그 시즌 실제 팀별 타석·이닝 분배 | **출장 시간이 누출됨.** 로스터를 알 때의 성능 상한 참고용 |

## 결과: 승수 오차 (162경기 환산, 10시즌 평균)

| 모델 | MAE | RMSE | 상관 | 누출 |
|---|---|---|---|---|
| model_actual | 7.92 | 9.70 | .671 | 있음 (참고용) |
| **model_blend** | **8.65** | **10.67** | **.560** | 없음 |
| model_prior | 8.77 | 10.83 | .543 | 없음 |
| regressed (.500 + 0.5 × 전년 이탈) | 8.84 | 10.85 | .535 | 없음 |
| last_wpct (전년 승률) | 9.97 | 12.19 | .535 | 없음 |
| flat_500 | 10.58 | 12.93 | - | 없음 |

- **누출 없는 모델은 강한 기준을 근소하게 이긴다.** model_prior 는 regressed 대비 −0.8%, model_blend 는 −2.2%.
- model_blend = .500 + a·(model_prior − .500) + b·(전년 피타고리안 − .500). a, b 는 직전 5시즌 OLS 로 매년 다시 맞춘다. 계수가 크게 흔들린다 (a 0.22~0.90, b 0.17~0.45). 모델 예측의 폭이 실제보다 넓어 줄여 써야 한다는 신호다.
- **로스터를 알면 MAE 가 1승 가까이 준다** (8.77 → 7.92). 팀 예측의 병목은 선수 실력 예측보다 출장 분배다. KBO 에서는 FA·트레이드 반영 로스터(roster_mode='user')를 넣는 것이 핵심이 된다.

## 결과: 확률의 보정

| 지표 | 모델 | 기준 |
|---|---|---|
| 포스트시즌 Brier (낮을수록 좋음) | **0.194** | 0.231 (진출 팀 수 / 팀 수) |
| 승수 80% 구간 적중률 | **0.803** | 명목 0.80 |

- σ(팀 실력 오차)는 직전 5시즌 잔차 분산에서 이항 잡음을 빼서 매년 다시 잡았다. 0.046~0.059 로 최근 커지는 추세.
- 2015 시즌만 Brier 가 기준보다 나빴다 (0.245 vs 0.222).

## 한계와 다음 단계

- 포스트시즌은 리그별 상위 k 팀으로 근사했다. 지구 우승 우선 규정은 무시했다. KBO 는 단일 리그 상위 5팀이라 이 근사가 정확하다.
- 수비·주루·파크팩터 미반영.
- 몬테카를로는 model_prior 기준이다. model_blend 로 옮기면 확률이 조금 더 보수적이 된다.
- 로스터 입력(user 모드)은 인터페이스만 있고 실제 사용 경로(KBO 로스터, FA 가정)는 P3 도구에서 연결한다.
